# UI Design Guide

## Visual direction
- Primary navy: `#172B4D`
- Secondary navy: `#243B63`
- Lavender accent: `#B9A7E8`
- Light background: `#F4F5FA`
- White cards: `#FFFFFF`
- Main text: `#1E293B`
- Secondary text: `#64748B`

## Layout
- Fixed left sidebar with LifeVault logo/title and navigation.
- Main content area with page title, short subtitle and page actions.
- Rounded cards with consistent spacing.
- Use consistent typography and button styles.
- Keep screens responsive to normal desktop window resizing.

## Screens
1. Dashboard: statistic cards, recent records, quick actions.
2. Memory Vault: memory cards/list, add/edit form, next/previous navigation.
3. Document Vault: document list, category filters, file browse/open action.
4. Achievement Vault: achievement cards and filters.
5. Life Timeline: chronological timeline with date/type filters.
6. Connections: choose records, create relationship, show neighbors and graph view.
7. Priority Vault: priority-ordered records with visible priority values.
8. Archive: archived records, restore and permanent delete confirmation.
9. Search: query field, type/category filters, results and empty state.
10. Data Structure Demo: small interactive examples or operation logs to demonstrate the ten structures.

## UX rules
- Every form has labels and validation feedback.
- Confirm destructive actions.
- Show success/error feedback.
- Provide empty states.
- Avoid decorative buttons that do nothing.
- Do not use emoji as the only way to identify an action.
- Maintain readable contrast and sensible font sizes.
